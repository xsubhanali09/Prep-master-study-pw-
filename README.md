# Prep Master Android

A simple Android WebView wrapper for the configured website.

## Build on GitHub
1. Upload this whole project to a GitHub repository.
2. Open **Actions**.
3. Select **Build Prep Master APK**.
4. Click **Run workflow**.
5. Open the successful run and download the **Prep-Master-debug** artifact.

App name: Prep Master
Package: com.prepmaster.app
Version: 1.0
Home URL: https://pwthor.live/auth

Use this wrapper only if you have permission to package/use the configured website.
